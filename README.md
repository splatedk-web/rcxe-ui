# rcxe-ui
Современный интерфейс UI для ARM64 Ubuntu, Debian. На данный момент на стадии разработки

Цель создать красивый интерфейс, который будет с анимациями, эффектами, мб Liquid Glass??? 
В отличие от XFCE интерфейс будет в разы современнее и привлекательнее, плавнее выглядеть, НО потреблять больше ресурсов.

Зачем это надо? такие окружения как Gnome не доступны и не совместимы с ARM64 процессорами, и на данный момент я не нашел хорошие аналоги за последние 5 лет...
