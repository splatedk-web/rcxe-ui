# rcxe-ui
Современный интерфейс UI для ARM64 Ubuntu, Debian. На данный момент на стадии разработки

Цель создать красивый интерфейс, который будет с анимациями, эффектами, мб Liquid Glass??? 
В отличие от XFCE интерфейс будет в разы современнее и привлекательнее, плавнее выглядеть, НО потреблять больше ресурсов.

Зачем это надо? такие окружения как Gnome не доступны и не совместимы с ARM64 процессорами, и на данный момент я не нашел хорошие аналоги за последние 5 лет...

# RXCE — Responsive Composite Environment (2026 Edition)

Next-Generation, Ultra-Modern Desktop Environment crafted specifically for **ARM64 (aarch64)** and Linux hardware (Raspberry Pi 4/5, Rockchip RK3588, Snapdragon X Elite, Apple Silicon Asahi Linux, Cortex big.LITTLE SBCs, Termux-X11/Wayland).

---

## 🌟 Основные особенности и возможности

RXCE переосмысляет классическую модульную философию XFCE в эстетике 2026 года с акриловым стеклом, аппаратно-ускоренным композитингом и физическими spring-анимациями:

### 1. Архитектура и дизайн
- **Glassmorphism & Specular Glow**: процедурные градиенты, глубокое размытие (Dual Kawase Blur), динамические тени с настраиваемым радиусом и неоновые акценты.
- **Движок тем оформления**:
  - `Cyber Glass 2026` (футуристичный неоновый стиль с глубоким акрилом)
  - `Deep OLED Pure Dark` (идеальный контраст с абсолютным черным для OLED-панелей)
  - `Aurora Borealis Glass` (бирюзово-изумрудное северное сияние)
  - `Nordic Frost Clean` (минималистичный скандинавский стиль)
  - `Tokyo Midnight Glow` (фиолетово-синий киберпанк)
- **Spring-анимации (60–144 FPS)**: затухающие гармонические осцилляторы для выпадающих меню, шторок и переходов между рабочими пространствами.

### 2. Специализированная оптимизация под ARM64
- **Поддержка топологии big.LITTLE / DynamIQ**: раздельный мониторинг маломощных энергоэффективных ядер (Cortex-A53/A55) и производительных ядер (Cortex-A76/A78/Prime-X).
- **ARM Governor Control**: мгновенное переключение профилей управления питанием (`powersave`, `schedutil`, `performance`) в один клик.
- **Термальный мониторинг**: чтение сенсоров `/sys/class/thermal/thermal_zone*` с цветной индикацией нагрева чипсета.
- **ZRAM & Память**: оптимизированная телеметрия для работы в условиях ограниченной оперативной памяти (< 25-35 МБ собственного потребления RAM).

### 3. Модули рабочего стола
- **RXCE Panel (Системная панель)**:
  - Кнопка вызова лаунчера с логотипом RXCE
  - Переключатель 4 виртуальных рабочих столов
  - Панель запущенных окон с индикацией активности и превью
  - Виджет телеметрии ARM64 (нагрузка CPU big.LITTLE, температура кристалла)
  - Системный трей (Wi-Fi, громкость звука, батарея, часы и календарь)
  - Кнопка Центра быстрых настроек
  - Настройка расположения (Сверху, Снизу, Слева, Справа, плавающий остров)
- **Modern App Launcher (Меню запуска)**:
  - Быстрый интеллектуальный поиск с ранжированием по релевантности и популярности запусков
  - Категории FreeDesktop: "Все", "Избранное", "Разработка", "Интернет", "Медиа", "Офис", "Система", "Параметры", "Игры"
  - Парсинг стандартных XDG `.desktop` файлов из `/usr/share/applications`
  - Панель действий сессии: Блокировка, Режим сна, Перезагрузка, Выключение
- **Quick Settings & Control Center (Шторка управления)**:
  - Быстрые интерактивные плитки 2x3 (Wi-Fi, Bluetooth, Ночной свет, ARM64 Governor, DND, Режим полета)
  - Слайдеры звука и яркости дисплея
  - Интегрированный MPRIS-медиаплеер с обложками и управлением треками
  - Центр уведомлений с очисткой и разделением по важности (Low/Normal/Critical)
- **RXCE Settings App (Центр параметров)**:
  - 7 категорий настроек: Персонализация, Панель, ARM64 & Питание, Дисплеи & Масштабирование, Оконный менеджер, Горячие клавиши, О системе
  - Сохранение в `~/.config/rxce/config.toml` с автоматической валидацией границ
- **Оконный менеджер и Композитор**:
  - Поддержка Smart Tiling (автоматическая сетка), горизонтального/вертикального сплита и классических плавающих окон
  - Интерактивные заголовки, перемещение, масштабирование, свернуть/развернуть/закрыть

## 🚀 Сборка и Запуск

### Запуск в режиме разработки на хосте
```bash
cargo run --release
```

### Сборка и запуск модульных тестов
```bash
cargo test
```

### Кросс-компиляция под ARM64 Linux (aarch64)
```bash
# Установка target в Rust
rustup target add aarch64-unknown-linux-gnu

# Сборка оптимизированного бинарного файла
cargo build --target aarch64-unknown-linux-gnu --release
```

## 📁 Структура проекта

```
├── src/
│   ├── lib.rs
│   ├── main.rs
│   ├── core/
│   │   ├── mod.rs
│   │   ├── apps.rs           # Индексатор XDG Desktop файлов и fuzzy search
│   │   ├── audio.rs          # Модель аудио и MPRIS контроллер плеера
│   │   ├── config.rs         # TOML-конфигурация с XDG-путями и валидацией
│   │   ├── network.rs        # Управление Wi-Fi, Ethernet и Bluetooth
│   │   ├── notifications.rs  # Диспетчер системных уведомлений и DND
│   │   ├── sysinfo.rs        # Телеметрия ARM64 big.LITTLE, температура и губернаторы
│   │   └── theme.rs          # Движок тем 2026, акриловое стекло, палитры
│   └── ui/
│       ├── mod.rs
│       ├── control_center.rs # Шторка быстрых настроек и уведомлений
│       ├── desktop.rs        # Рабочий стол, обои, иконки, контекстное меню
│       ├── launcher.rs       # Меню запуска приложений со spring-анимацией
│       ├── panel.rs          # Системная панель задач и трея
│       ├── settings_app.rs   # Полнофункциональное приложение параметров
│       ├── window_manager.rs # Оконный менеджер и тайлинг-движок
│       └── components/
│           ├── mod.rs
│           ├── glass.rs      # Рендерер акрилового стекла, теней и бликов
│           ├── spring.rs     # Пружинная физика анимаций 60-144 FPS
│           └── widgets.rs    # Неоновые кнопки, тумблеры, слайдеры, бейджи
└── tests/
    └── core_tests.rs         # Модульные и интеграционные тесты
```
